# A Non-Axiomatic Reccomendation System

This repository contains a prototype of a reccomendation system that utilizes Pei Wang's non-axiomatic reasoning system. Visit their site [HERE](https://cis.temple.edu/~pwang/) to learn more about NARS, it's theory, implementations, and uses.

Read the paper included in this repository for the motivation, design, and usage of this reccomendation system.
